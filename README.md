# 🚗 ระบบบันทึกการใช้รถบริษัท

เว็บสำหรับบันทึกเลขไมล์ตอนรับและคืนรถบริษัท ระบบจะตรวจจับความผิดปกติให้เอง และส่งแจ้งเตือนเข้า LINE

- **หน้าเว็บ** (`index.html`) ใช้ GitHub Pages ฟรี
- **หลังบ้าน** (`apps-script/Code.gs`) ใช้ Google Sheet + Apps Script ฟรี ข้อมูลเก็บใน Sheet และรูปเก็บใน Google Drive

## ระบบทำอะไรได้บ้าง

**สำหรับพนักงาน** (ใช้บนมือถือได้ ไม่ต้องติดตั้งแอป)
- สแกน QR ในรถ แล้วหน้ารับรถหรือคืนรถของคันนั้นจะเปิดขึ้นมาทันที
- กรอกเลขไมล์และถ่ายรูปหน้าปัด ระบบจะประทับทะเบียนรถและเวลาลงบนรูปให้
- เลือกว่าไปทำอะไร และ**ค้นหาสถานที่จาก Google Maps** ได้หลายจุด (พิมพ์ชื่อแล้วแตะเลือก หรือวางลิงก์ที่แชร์จากแอป Google Maps)
- ระบบคำนวณระยะ บริษัท → ทุกจุด → กลับบริษัท และบอกว่า**กลับถึงบริษัทเลขไมล์ควรเป็นเท่าไหร่**
- ตอนคืนรถ ระบบเทียบเลขไมล์จริงกับที่ควรเป็นให้ทันที และกรอกการเติมน้ำมันได้ด้วย
- **ถ่ายรูปใบเสร็จน้ำมัน** ระบบอ่านลิตรและยอดเงินมากรอกให้ เก็บรูปไว้ตรวจ และเตือนถ้าตัวเลขที่กรอกหรือวันที่ในใบเสร็จไม่ตรง
- **ราคาน้ำมันจริงวันนี้** (ดึงจากประกาศของบางจากอัตโนมัติ): กรอกลิตรหรือบาทช่องเดียว อีกช่องคำนวณให้ ถ้ายอดเงินในใบเสร็จไม่ตรงกับราคาวันนี้เกิน 5% ระบบแจ้งเตือน และประมาณค่าน้ำมันของแต่ละเที่ยวจากระยะทาง

**ระบบติดธงแจ้งเตือนอัตโนมัติเมื่อ**
| กรณี | ตัวอย่าง |
|---|---|
| เลขไมล์ไม่ต่อกัน | คืนรถครั้งก่อนที่ 45,291 แต่ครั้งนี้รับรถที่ 45,338 → มี 47 กม. ที่ไม่ได้บันทึก |
| วิ่งเกินระยะที่ควรเป็น | Google Maps คำนวณว่าไป-กลับ 30 กม. แต่วิ่งจริง 103 กม. |
| ใช้รถนอกเวลางาน / วันหยุด | คืนรถตอน 20:30 |
| ไม่คืนรถภายในวัน / ใช้รถนานเกินไป | เอารถกลับบ้านค้างคืน |
| คืนรถไม่ใช่ที่บริษัท | พิกัด GPS ของมือถือตอนคืนรถอยู่ห่างจากบริษัทเกิน 1 กม. |
| รูปเลขไมล์ไม่ได้ถ่ายสด | ใช้รูปเก่าจากแกลเลอรี |

**บันทึกเส้นทาง GPS จากมือถือ (โหมดกำลังขับ)**
- หลังรับรถ กด **เริ่มขับ บันทึกเส้นทาง** แล้ววางมือถือเปิดหน้าจอค้างไว้ในรถ (ควรเสียบสายชาร์จ) ระบบกันจอดับและเก็บพิกัดทุก ~1 นาที
- ส่งข้อมูลขึ้นระบบทุก 1 นาที ถ้าเน็ตหลุดจะเก็บไว้ในเครื่องแล้วส่งภายหลัง
- ตอนคืนรถ ระบบตรวจว่า GPS ขาดช่วงไหม (แปลว่าปิดหน้าจอหรือปิดเว็บ) รถออกนอกเส้นทางที่วางไว้ไกลแค่ไหน และระยะจาก GPS ตรงกับเลขไมล์ไหม
- ผู้ดูแลกด **ดูเส้นทางบนแผนที่** ในหน้ารายงานได้ (ข้อมูลพิกัดอยู่ในแท็บ `Track` ของ Google Sheet)
- ข้อจำกัด: หน้าเว็บเก็บตำแหน่งได้เฉพาะตอนเปิดหน้าจอค้างไว้ ถ้าล็อกจอ ระบบจะหยุดเก็บ (และแจ้งเตือนว่าขาดช่วง)

**ติดตามรถสด (ผู้ดูแล)**
- หน้ารายงาน → **ติดตามรถสด** แผนที่เต็มจอ เห็นรถทุกคันที่กำลังใช้งาน อัปเดตเองทุก 15 วินาที
- แผ่นรายละเอียดด้านล่างบอกว่าใครขับ กำลังไปจุดไหน ผ่านจุดไหนแล้ว ความเร็ว ระยะที่วิ่ง อัปเดตล่าสุดเมื่อไหร่ และเลขไมล์ที่ควรกลับมา
- รถออกนอกเส้นทางเกิน `GPS_OFFROUTE_KM` ไอคอนเปลี่ยนเป็นสีแดงทันที ถ้าไม่ได้รับตำแหน่งเกิน 3 นาทีจะเป็นสีเทา
- แผนที่ใช้ภาพจาก CARTO/OpenStreetMap (ใช้ฟรีสำหรับปริมาณการใช้งานน้อย ถ้าใช้เชิงพาณิชย์ปริมาณมากควรดูเงื่อนไขของ CARTO)

**สำหรับผู้ดูแล** (แท็บ "รายงาน" ต้องใช้ PIN ผู้ดูแล)
- รายการที่ถูกเตือน กด **ตรวจแล้ว** พร้อมบันทึกผล (เช่น สอบถามแล้ว ตักเตือนแล้ว) รายการจะย้ายไปส่วน "ตรวจแล้ว" และเก็บเป็นหลักฐานย้อนหลัง
- สรุปรายเดือนของรถแต่ละคัน ได้แก่ จำนวนกิโลเมตร จำนวนครั้ง กม./ลิตร และค่าน้ำมัน
- รายการที่ต้องตรวจสอบ สรุปรายคน และรายการทั้งหมดพร้อมรูป
- ดาวน์โหลดเป็น CSV เปิดด้วย Excel ได้
- พิมพ์ QR code ไปติดในรถได้

## วิธีติดตั้ง

### ขั้นที่ 1: ลองใช้โหมดทดลองก่อน (ไม่ต้องตั้งค่าอะไร)
อัปไฟล์ขึ้น GitHub แล้วเปิด GitHub Pages ตามขั้นที่ 4 ได้เลย ถ้ายังไม่ได้ใส่ `API_URL` ระบบจะทำงานใน**โหมดทดลอง** โดยเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น (PIN พนักงาน: สมชาย 111111, สมหญิง 222222, สมศักดิ์ 333333 และ PIN หน้ารายงานคือ `9999`)

### ขั้นที่ 2: สร้างหลังบ้านใน Google Sheet
1. ใช้บัญชี Google ของบริษัท สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "บันทึกการใช้รถ"
2. ไปที่เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
4. แก้ค่าใน `CONFIG` ด้านบนของโค้ด
   - `CARS` ใส่ชื่อ ทะเบียน ชนิดน้ำมัน (`fuel` เช่น `diesel`, `g95`) และอัตราสิ้นเปลือง (`kmPerLiter` กม./ลิตร) ของรถ 2 คัน
   - `DRIVERS` ใส่ชื่อพนักงานและ **PIN ของแต่ละคน** (ห้ามซ้ำกัน แนะนำ 6 หลัก) ระบบรู้ว่าใครใช้รถจาก PIN นี้ จึงสวมชื่อคนอื่นไม่ได้
   - `ADMIN_PIN` (PIN ผู้ดูแล) **ต้องเปลี่ยนจากค่าเริ่มต้น**
   - `COMPANY_LAT` / `COMPANY_LNG` หาได้โดยเปิด Google Maps คลิกขวาที่ตำแหน่งบริษัท แล้วคลิกที่ตัวเลขพิกัดเพื่อคัดลอก
   - ตั้งเวลางานได้ที่ `WORK_START` / `WORK_END` / `WORK_DAYS`
5. **เปิด Drive API** (ใช้อ่านใบเสร็จน้ำมันอัตโนมัติ): ที่เมนูซ้ายของ Apps Script กด **บริการ (Services) +** → เลือก **Drive API** → กด **เพิ่ม**
6. กดบันทึก (💾)

> ⚠️ ใส่ PIN และ LINE token จริงในหน้า Apps Script เท่านั้น **อย่า**แก้ไฟล์ `Code.gs` ใน GitHub ให้มีค่าจริง เพราะ repo ที่ใช้ GitHub Pages แบบฟรีต้องเป็น public

### ขั้นที่ 3: Deploy เป็น Web App
1. ในหน้า Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง แล้วเลือก **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
3. กด Deploy แล้วกดอนุญาตสิทธิ์ (Google จะขอสิทธิ์ Sheet, Drive และ Maps)
   - ถ้าเจอหน้า "Google hasn't verified this app" ให้กด Advanced แล้วกด Go to … (unsafe) ได้ เพราะเป็นสคริปต์ของเราเอง
4. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
5. เปิด `index.html` ใน GitHub แล้วกดรูปดินสอเพื่อแก้ไข ใส่ URL ตรงบรรทัดนี้
   ```js
   const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```

> 💡 ถ้าแก้ `Code.gs` ภายหลัง ต้องไปที่ **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่** ทุกครั้ง แบบนี้ URL จะยังเหมือนเดิม

### ขั้นที่ 4: เปิดเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub แบบ Public แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ **Settings → Pages**
3. ตรง Source เลือก **Deploy from a branch** ตั้ง Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1–2 นาที จะได้ลิงก์แบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

### ขั้นที่ 5: ติด QR ในรถ
เปิดเว็บ ไปที่แท็บ **รายงาน** แล้วเลื่อนลงล่างสุด กด **พิมพ์** QR code ของรถแต่ละคันไปติดไว้ในรถ ตอนพนักงานใช้ครั้งแรก ให้กรอก PIN ของตัวเองหนึ่งครั้ง (มือถือจะจำไว้ กดชื่อมุมขวาบนเพื่อออกจากระบบ) และกดอนุญาตให้เว็บเข้าถึงตำแหน่ง

### ขั้นที่ 6: แจ้งเตือนเข้า LINE (ไม่บังคับ)
1. สร้าง LINE Official Account ที่ [LINE Official Account Manager](https://manager.line.biz/) แล้วไปที่ **ตั้งค่า → Messaging API** เพื่อเปิดใช้งาน
2. ไปที่ [LINE Developers Console](https://developers.line.biz/console/) เลือก channel ของ OA นั้น แล้วไปแท็บ **Messaging API**
   - กด **Issue** ตรง Channel access token (long-lived) แล้วคัดลอกไปใส่ `LINE_CHANNEL_TOKEN` ใน Code.gs
   - ใส่ URL เว็บแอปจากขั้นที่ 3 ในช่อง **Webhook URL** แล้วเปิด **Use webhook**
   - เปิด **Allow bot to join group chats**
3. Deploy เวอร์ชันใหม่ (ดูหมายเหตุในขั้นที่ 3)
4. เชิญ OA เข้ากลุ่ม LINE ของหัวหน้า แล้วพิมพ์ในกลุ่มว่า `ตั้งค่าแจ้งเตือน 9999` (ใช้ ADMIN_PIN ของคุณแทน 9999) บอทจะตอบกลับว่าตั้งค่าแล้ว
   - ถ้าข้ามขั้นนี้ ระบบจะ broadcast ไปหาทุกคนที่เพิ่มเพื่อน OA แทน
5. ทดสอบได้โดยเลือกฟังก์ชัน `testLine` ในหน้า Apps Script แล้วกด Run

ถ้าตั้ง `LINE_NOTIFY_ALL: false` ระบบจะแจ้งเฉพาะรายการที่ผิดปกติ ซึ่งช่วยประหยัดโควตาข้อความของ OA แพ็กเกจฟรี

## ข้อควรรู้
- **PDPA:** ระบบเก็บพิกัดจากมือถือ**เฉพาะระหว่างใช้รถบริษัท** (หลังกดเริ่มขับจนคืนรถ) ควรแจ้งพนักงานเป็นลายลักษณ์อักษรและให้รับทราบก่อนใช้งาน
- **PDPA:** ควรแจ้งพนักงานเป็นลายลักษณ์อักษรว่าระบบเก็บรูปเลขไมล์และพิกัด GPS **เฉพาะตอนรับและคืนรถ** เพื่อควบคุมการใช้ทรัพย์สินบริษัท และใส่เรื่องนี้ไว้ในนโยบายการใช้รถ
- ถ้าพนักงานลาออกหรือ PIN หลุด ให้ลบหรือเปลี่ยน PIN ของคนนั้นใน `DRIVERS` แล้ว Deploy เวอร์ชันใหม่ (เครื่องที่ใช้ PIN เดิมจะถูกออกจากระบบเอง)
- ข้อมูลทั้งหมดอยู่ในแท็บ `Trips` ของ Google Sheet ส่วนรูปอยู่ในโฟลเดอร์ "รูปเลขไมล์รถบริษัท" ใน Google Drive
- ค่า กม./ลิตร จะแม่นขึ้นถ้าพนักงานกรอกการเติมน้ำมันทุกครั้ง (หรือเติมเต็มถังทุกครั้ง)
- ระบบนี้ป้องกันได้ดีในระดับหนึ่ง ถ้าต้องการความแม่นยำ 100% ควรติด GPS tracker ในรถเพิ่ม
